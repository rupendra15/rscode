# Vistaar-Biz

AI-powered local-business growth command centre.

## Run
Open index.html in a browser. No Node.js, npm, build step, or external backend is required for this standalone prototype.

## Included
- Growth Audit
- AI Growth Manager UI
- Leads & Conversion
- Expert matching
- Execution Studio
- Measure & Learn
- Business onboarding
- Local browser persistence via localStorage

This standalone build is designed to get the product running immediately while the production Next.js/Supabase version is developed separately.
